# 🗺️ AI Land Parcel Zoning & Compliance App

An AI-assisted geospatial application designed to audit registered land parcel boundaries against municipal zoning regulations and generate instant spatial compliance reports.

## 🚀 Features
- **Spatial Overlay Analysis:** Spatial join of parcel polygons with vector zoning layers using GeoPandas & Shapely.
- **Rule Verification:** Automatic evaluation of land use, building height, ground coverage %, and setback requirements.
- **Interactive Mapping:** Keyless OpenStreetMap basemap rendering via Folium.
